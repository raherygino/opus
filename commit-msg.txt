Fix desktop CSP: allow OSM tile fetches via connect-src

The OSM embed iframe fetches map tiles using fetch/XHR, which is
governed by connect-src — not img-src. The previous CSP only allowed
OSM tiles in img-src, so tile requests were blocked with:
  "Refused to connect to 'https://tile.openstreetmap.org/...'"

Added https://*.tile.openstreetmap.org and https://tile.openstreetmap.org
to connect-src in both CSP sources:
  - desktop/index.html (meta tag)
  - desktop/electron/main.ts (HTTP header)
